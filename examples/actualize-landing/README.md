# Actualize AI Design Landing Page

> **A showcase of anime.js v4 powering modern, animated web applications through minimal, clever AI design previews.**

## Project Vision

This landing page demonstrates how anime.js v4 can power sophisticated, modern web applications. Built as a showcase for "Actualize"—an AI design platform that transforms ideas into professional designs—it serves as both a functional demo and a template for building animated web experiences.

## Design Preview Philosophy

**These are CAPABILITY PREVIEWS, not detailed design renders!**

- Each mockup is a minimal, clever showcase that demonstrates Actualize's ability to:
  - Distinguish between design types (logo, poster, mobile app, etc.)
  - Respond distinctively to prompts (each preview looks different)
  - Generate relevant visual concepts (quick capability demonstration)
- **Not** full design deliverables or production-ready designs.

## What This Showcases

- **Elegant Entrance Animations**: Staggered, modular reveals for each design type
- **Typewriter Input**: Smooth, natural text animation with persistent prefix
- **Dynamic Mockup Generation**: Real-time design previews that transform based on content
- **Interactive Feedback**: Hover states, focus effects, and micro-interactions
- **Background Ambiance**: Subtle moving light effects and ambient animations
- **Lively Generation State**: Animated dots for "Generating design..." status
